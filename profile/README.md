# Host-Pathogen-Biology

### ABOUT
The Host and Pathogen Biology group at the Institute for Respiratory Health (Perth, WA) studies how host responses and infecting pathogens interact to drive chronic respiratory disease. This organisation hosts the group's computational work: genome assembly and annotation of clinical fungal and bacterial isolates, comparative and functional genomics, protein structure prediction, and transcriptomic analysis of host immune cells. 

Repositories here hold reproducible pipelines, analysis code, and supporting tools, built to be portable across local workstations and HPC.
